Instructions

Download the ZIP file
In your download folder the program will automatically appear, you won't need to unzip it
Hold ctrl when clicking the file and then select the open option from the 
MAC OS will want you to confirm you want to open it as the program is currently unrecognized and doesn't know if it's a dangerous file. On later openings it shouldn't have the issue but if it does you may need to adjust the security settings to allow this file to work
It may ask you to allow it access to the file manager here or when you click the file upload button
Allow access that way it can find the pdf files and place it in the same directory

When the terminal that opens behind the file upload button says "done" the program is complete and the excel file will be in the same folder as the original pdf
